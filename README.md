# save-ducky

Static marketing, help, support, and privacy website for Save Ducky.

Canonical domain: https://save-ducky.luopeike.com

Locales: root x-default plus en-US, zh-Hans, zh-Hant, ja, ko, es, pt-BR, it, id, fr, de.

SEO notes:
- Each locale has its own directory path.
- Pages include canonical, hreflang, Open Graph, Twitter card, JSON-LD, robots, sitemap, and theme-color metadata.
- Social cards use a 1200x630 preview image for large link previews.
- Download calls to action use an App Store icon and point to the public App Store listing.
